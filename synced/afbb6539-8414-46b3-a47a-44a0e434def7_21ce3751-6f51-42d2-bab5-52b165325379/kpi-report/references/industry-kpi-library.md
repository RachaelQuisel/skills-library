# Industry KPI Library

Reference library for generating KPI recommendations by client type. Use this when a transcript reveals the client's industry and you need to suggest metrics they didn't mention.

---

## Media / Publishing (e.g., AY Media Group)

**Revenue KPIs**
- Ad revenue by publication / issue
- Revenue per advertiser
- Revenue per ad type (display, sponsored content, digital, print)
- Renewal rate (returning advertisers)
- Average deal size
- Revenue per sales rep

**Operations KPIs**
- Time from agreement signed to invoice sent
- Time from invoice sent to payment received
- Ad materials submission rate (on time vs. late)
- Production error rate (ads requiring re-do)
- % of agreements with missing materials at deadline

**Sales KPIs**
- Leads in pipeline by stage
- Conversion rate (proposal → signed agreement)
- Sales cycle length (first contact → close)
- Rep activity (outreach attempts, calls, meetings)

**Gaps to flag if not mentioned:**
- Who owns renewal outreach? If no one's tracking it, renewals fall through the cracks.
- Digital vs. print revenue split — if they're shifting to digital, this becomes critical.

---

## Education / Certification (e.g., Coding Clarified)

**Student KPIs**
- Enrollment count (total, by cohort, by state)
- Completion rate
- Pass rate (first attempt, overall)
- Average time to completion
- Student drop-off point (which module/stage)

**Operations KPIs**
- Time from enrollment to system access granted
- Caseworker-to-student ratio
- Support ticket volume and resolution time
- Document submission rate (on time vs. late)

**Revenue / Business KPIs**
- Revenue per student
- Cohort fill rate (seats sold vs. available)
- Refund / withdrawal rate

**Gaps to flag if not mentioned:**
- Outcome tracking post-certification — do they know if students are getting jobs?
- State-specific pass rates — if they operate in multiple states, this matters for compliance.

---

## Nonprofit / Wellness (e.g., The HOPE for Health)

**Program KPIs**
- Participant enrollment by cohort / track
- Participant retention rate (attended X of Y sessions)
- Program completion rate
- Participant satisfaction (if surveys exist)

**Volunteer / Coach KPIs**
- Active volunteers / coaches
- Volunteer-to-participant ratio
- Volunteer retention rate

**Outreach KPIs**
- Referral sources (where participants come from)
- Application-to-enrollment conversion rate
- Waitlist size

**Funding / Donor KPIs** (if applicable)
- Donor count and retention rate
- Grant utilization rate
- Cost per participant served

**Gaps to flag if not mentioned:**
- Impact metrics — funders want outcome data, not just participation numbers.
- If volunteer scheduling is manual, that's a gap waiting to become a crisis.

---

## Professional Services / Consulting

**Revenue KPIs**
- Revenue by client
- Utilization rate (billable hours / available hours)
- Average project value
- Recurring vs. project revenue split

**Operations KPIs**
- On-time delivery rate
- Scope change frequency
- Client onboarding time

**Client KPIs**
- Client retention / churn rate
- Net promoter score (if tracked)
- Upsell / expansion revenue

---

## E-commerce / Product

**Sales KPIs**
- Revenue (daily, weekly, monthly)
- Average order value
- Conversion rate
- Cart abandonment rate

**Customer KPIs**
- Customer acquisition cost
- Lifetime value
- Repeat purchase rate
- Refund / return rate

**Operations KPIs**
- Fulfillment time
- Inventory turnover
- Out-of-stock rate

---

## Short-Term Rental / Property (e.g., La Maison)

**Revenue KPIs**
- Occupancy rate
- Average daily rate (ADR)
- Revenue per available night (RevPAR)
- Revenue by platform (Airbnb, VRBO, direct)

**Operations KPIs**
- Cleaner no-show / late rate
- Maintenance issue resolution time
- Guest complaint rate
- Check-in issue rate (lock problems, access issues)

**Guest KPIs**
- Average review score (by platform)
- Review response rate
- Repeat guest rate

---

## Notes for Using This Library

- Always tie recommendations to something specific the client said — don't carpet-bomb them with every KPI in their category.
- If the client is in a category not listed here, reason from first principles: what decisions do they need to make, and what data would help them make those decisions better?
- Confidence levels: if a KPI is listed here but wasn't implied by anything in the transcript, mark confidence as Low.
