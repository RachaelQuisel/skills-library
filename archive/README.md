Skills here are retired. They are kept for history and are not installed, registered or tested.
Each one's `SKILL.md` is renamed `SKILL.archived.md` so no installer or inventory check treats it as active.

| `pdf-builder` | 2026-11-13 | Removed from the repo by auto-sync on 2026-06-26; copy kept from the claude.ai account |
| `sprint-summary` | 2026-11-13 | Removed from the repo on 2026-04-07; copy kept from the claude.ai account |
| `todays-focus` | 2026-11-13 | Removed from the repo on 2026-04-07; copy kept from the claude.ai account |

Files inside each archived skill still use their pre-archive paths (for example links to `SKILL.md`); they work again once the skill is restored.

To restore one, move it back to the repo root, rename `SKILL.archived.md` to `SKILL.md`, and re-add it to `maintenance/collection.json`.
