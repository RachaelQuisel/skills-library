# client-doc-build-plan

Drafts or updates the canonical `build-plan.md` for a client build: Projects, Outcomes, and Tasks from the tasks.xray.tech API, or drafted from every meeting debrief and transcript (verified against the recordings) when the project has no outcomes or tasks in the system yet.

Part of the Client Docs plugin. Install:

```
/plugin install client-docs --marketplace RachaelQuisel/Skills
```
