# Apply Rachael's house style to HTML artifacts

This skill helps you apply Rachael's usual HTML artifact look: a Luma-inspired pink graph-paper ground, Space Grotesk headings, JetBrains Mono body text, and small pixel accents. Use it for her artifacts unless she asks for a different visual direction.

## What to share

Describe the page or document and any visual direction she has already given.

## How to start

Select this skill and describe your request. The assistant uses the information and tools available in that conversation.

## Detailed guidance

The [working instructions](SKILL.md) describe the style, typography, palette, and when a different brand skill should be used instead. The [sprite notes](references/sprites.md) and [palette notes](references/palette.md) keep the supporting details.
