# make-it-sound-human

Turn a technical report, data check, audit, comparison, or assistant-generated summary into a friendly, client-facing XRAY-branded PDF that reads like Rachael wrote it. The reader dislikes technology and reads at about an 8th-grade level. Use this whenever Rachael pastes a report and wants it "for the client," "in plain English," "for someone non-technical," "client-facing," "in my voice," or "to sound human." Examples include an Instinct check, an Airtable or Acuity comparison, a reconciliation, or a status report. Use it even if she does not say PDF or name this skill.

The working instructions are in `SKILL.md`.
