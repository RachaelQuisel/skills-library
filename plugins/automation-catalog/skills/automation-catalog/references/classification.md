# Categories and tags

| Label | Meaning | Examples |
|---|---|---|
| Category | Business area | Bookings, Cleaning, Guest Communication, Maintenance, Accounting, Inventory, Reporting, Sales, Client Delivery, People, Personal |
| Type | What it does | Data sync, Data import, Form intake, Notifications, Checks and alerts, Scheduling, Approval routing, Document preparation, Data analysis, Reply assistance |
| Tools | Tools named in sources | Airtable, Python, Slack, Google Apps Script |
| Runs | Where or how it starts | Cloud verified, Cloud setup unverified, Manual start, Planned, Unknown |

Reuse the business's vocabulary. Give each workflow one primary category and type. Group by business first, then category. Keep client information in that client's approved index.

Use lowercase hyphenated tags such as `#accounting`, `#data-sync`, `#airtable`, `#manual-start` and `#cloud-unverified`. Keep them consistent between documents and Slack. A tool tag does not establish a live connection. Label planned tools as planned.

Keep status separate. Manual start does not prove where a tool is hosted. Cloud verified requires current evidence of the relevant hosted schedule or service. Code that could run in the cloud remains unverified until that evidence exists.
