# Data use

This package contains instructions, reference text, a local Python preparation helper and offline tests. It has no publisher-operated server, account, telemetry or storage service.

The helper reads the supplied inventory JSON and writes local Markdown files and a publication-plan JSON file. It makes no network requests. It does not read credential stores or environment variables. The package has no hooks, executable launchers or bundled Model Context Protocol server.

During a user-requested or separately scheduled run, the host may read workflow definitions, source code, project documents, messages, task settings and delivery evidence. These can contain business or personal information. The host and connected services process these requests under their own permissions and terms.

The instructions permit saving guides to approved project locations and posting or editing approved Slack messages. The receiving service receives that content and normal request information. Separate business records and audience checks are instructions to the agent. The host's tools and permissions control the actions that are technically possible.

The README's dollar-prefixed skill name is Codex invocation syntax. It does not read a credential or assemble a shell command. The helper's network behavior was inspected separately from this documentation.

Outputs remain in the selected project, local output folder, messaging destination and host conversation under their retention policies. The plugin does not create a publisher copy. Account-specific schedules and channel identifiers are not part of this distributed package.
