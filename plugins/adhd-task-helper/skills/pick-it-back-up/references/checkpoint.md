# Portable restart checkpoint

Use only the fields the actual task needs. Keep the note compact, concrete, and copyable. Preserve essential file locations or links rather than saying "the document."

```text
Goal:
Done:
Where I stopped:
Next action:
Blocker or open question: [only if relevant]
Relevant files or links: [only if available]
```

Retain the distinction between a draft, an attempted action, a confirmed save, and a completed external action. State uncertainty where it affects resuming. Do not include credentials or irrelevant personal information. Include communication preferences only when the user asks for them to travel with the note.

Example based on fictional source material:

```text
Goal: Send a maintenance request about the leaking kitchen sink.
Done: Message draft prepared; not sent.
Where I stopped: The property address still needs to be added.
Next action: Add the address and review the draft before sending.
```

When no save destination is requested, supplying the note in chat is enough. Report it as a copyable note, not as a file saved elsewhere or something every future chat will automatically remember.
