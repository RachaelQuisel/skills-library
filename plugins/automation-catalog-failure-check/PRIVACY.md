# Data use

This package contains instructions, reference text and a PNG icon. It has no scripts, hooks, executable launchers, publisher-operated server, telemetry, credential storage or bundled Model Context Protocol server.

A requested or separately scheduled check asks the host to read task settings, run times, status messages, report threads, attempt counts and delivery evidence. This information can contain business or personal details. Use only the task and destinations authorized by the user.

The host may send a failure alert to an approved messaging destination. That service receives the alert and normal request information under the user's existing connection. If delivery fails, the host conversation receives the failure report.

The instructions require audience checks, minimal disclosure and verified delivery. These are instructions to the agent. The host's enabled tools and permissions determine what actions are technically possible.

The plugin has no publisher copy of this content. Outputs remain in the selected messaging service, private delivery record and host conversation under their retention policies. Personal task and channel identifiers stay outside the distributed package.

Questions can be sent through the private Skills repository's issue tracker: https://github.com/RachaelQuisel/Skills/issues
