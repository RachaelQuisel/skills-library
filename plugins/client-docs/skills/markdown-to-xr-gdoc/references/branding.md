# XRAY Branding Reference

## Colors
- **Page Background:** `floralwhite`
- **Headings:** `#0e1c2d` (Gray 900)
- **Body Text:** `#686f76` (Gray 600)
- **Primary CTA / Links:** `#1566b9` (Blue 500)
- **Links Hover:** `#0f4185` (Blue 700)
- **Borders:** `#e1ded8` (Gray 200)
- **Muted Text:** `#868b8e` (Gray 500)

## Typography
- **Headings (h1-h5):** `new-order`, fallback `'Urbanist', sans-serif`. Use negative letter-spacing.
- **Body & UI:** `mundial`, fallback `'Figtree', sans-serif`.
- **Sizes:**
    - h1: 56px, weight 700, line-height 64px, -1px letter-spacing
    - h2: 40px, weight 700, line-height 48px, -1px letter-spacing
    - h3: 32px, weight 700, line-height 40px, -1px letter-spacing
    - Body (p): 16px, weight 400, line-height 24px, -0.5px letter-spacing

## Components
- **Container:** Max width 1280px, 1024px, 846px, or 776px.
- **Cards:** `.content-card` (background `floralwhite`, radius 24px, padding 40px).
- **Buttons:** `.button` (background `#1566b9`, radius 8px, padding 16px 24px).
