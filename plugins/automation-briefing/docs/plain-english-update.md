# Plain-English update

Version 1.0.1. Updated October 11, 2026, using Voice Align.

The instructions and README now use Trigger, Inputs, What happens, and Outputs. The writing rules apply to the brief sent to the user. They require short sentences, everyday words, explained technical terms, and a clear next step. The report limits, source checks, recipient checks, repeat prevention, and delivery checks are preserved.

For example, use 'check which account can edit records' instead of 'review permission implications.' Explain Test, Change, and Watch through the recommended action.

Skill frontmatter and the publishing package checks were run locally. The changes affect wording and instructions. They do not establish Claude installation, live compatibility, or successful delivery. The earlier validation record describes version 1.0.0.
