# Name choice

Candidates: Automation Briefing, Business Automation Briefing, Automation Update Brief, Workflow Tool Brief.

Recommended: **Automation Briefing**. It names the job directly, stays short in a plugin menu, and includes the search terms people use. The description supplies the business, no-code, and AI scope.

Tagline: Know which automation changes deserve a test, a workflow update, or a watchlist entry.
