# Data handling

This instruction-only plugin uses the conversation and relevant project material supplied by the user or read through authorized host tools. This may include repository files, Airtable schema and records, integration details, and identifiers.

Tool requests go to the connected services used for the task. The host and those services apply their own permissions and data policies. The publisher operates no backend for this plugin, and the package includes no telemetry, hooks, credential storage, or scheduled jobs.

Output appears in the conversation. The user may paste it into Zite, where Zite's policies apply. The instructions require a separate request before executing a prompt in Zite. These are behavioral instructions, not a technical access control.

Do not include secrets or unrelated personal data in prompts. File saves or external writes require authorization from the task and host.
