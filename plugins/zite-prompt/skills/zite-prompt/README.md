# Write a focused request for the next Zite build step using the information already confirmed

This skill helps you write a focused request for the next Zite build step using the information already confirmed.

## What to share

Describe the result you need and share the relevant files, notes, or examples you want this skill to use.

A good request names four things: the page and what you saw (with a screenshot if you have one), who it's for and on what device, what "done" looks like in one sentence, and any limits such as "just this page" or "don't publish". Example: "On the Activities page on my phone, the Watch Back banner overlaps the heading. Fix just that, don't publish, and log it in the fix log."

## How to start

Select this skill and describe your request. The assistant uses the information and tools available in that conversation.
