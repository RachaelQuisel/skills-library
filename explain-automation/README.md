# explain-automation

Turn an Airtable automation into a plain-English explainer and share it with the client. Reads the automation's real configuration, writes a no-jargon education doc in bullet points (trigger, inputs, steps in order, outputs, what happens when it fires), and posts it to the client's Slack huddle channel with a threaded reply carrying the direct automation links and a step-by-step breakdown. Use this whenever the user asks to explain an automation, educate the client on an automation, document what an automation does, write an automation explainer, post an automation explainer to Slack, or announce that an automation went live — even if they only say "tell the team what this does" or "write this up for Janine.

The working instructions are in `SKILL.md`.
