# Apply XRAY's colors, fonts, logo, and visual standards to a deliverable

This skill helps you apply XRAY's colors, fonts, logo, and visual standards to a deliverable.

## What to share

Describe the intended result, where it will appear, and any existing design examples or brand requirements.

## How to start

Select this skill and describe your request. The assistant uses the information and tools available in that conversation.

## Document models

Use the [King Changelog](examples/king-changelog.pdf) for dated updates and [King Decisions Made](examples/king-decisions.pdf) for decision records. These private examples show how to arrange the logo, headings, and text on a floralwhite page. Write new content for each project.
